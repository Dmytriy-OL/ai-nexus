# Architecture Decision Records (ADR)

When making significant technical choices, an ADR must be created. 
Format:
1. **Title**: The decision.
2. **Context**: What is the problem?
3. **Decision**: What is the chosen solution?
4. **Consequences**: What becomes easier or harder?

In this project, ADRs are implicitly applied to choices like choosing Next.js App Router over Pages, using Framer Motion for performance, and selecting Tailwind CSS for strict design system adherence.
